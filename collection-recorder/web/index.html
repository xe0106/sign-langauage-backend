촬영 가이드와 NO_SIGN 예시
  • 정면을 보고 상반신과 양손을 항상 화면 안에 둡니다.
  • 대기 자세 → 수어 → 대기 자세 순서로 수행합니다.
  • 각 10회 안에서 빠르게·보통·느리게 속도를 섞습니다.
  • 2차 세션은 가능하면 옷·조명·배경을 조금 바꿉니다.
  • 동작을 틀렸다면 완료 번호를 선택해 즉시 다시 촬영합니다.

NO_SIGN: NO_SIGN(비수어 동작)은 표정만을 뜻하는 게 아니라, 모델이 10개 학습 단어 중 어느 것도 아니라고 판단해야 하는 모든 상황을 의미합니다. 예시는 다음과 같습니다. - 아무 동작 없이 가만히 있기 - 손을 내리고 대화하기 - 머리카락이나 얼굴 만지기 - 안경 고치기 - 옷 정리하기 - 기지개 켜기 - 손 흔들기 - 박수 치기 - 화면이나 물건 가리키기 - 컵이나 휴대전화 들기 - 손을 화면 밖으로 움직이기 - 수어 시작 전 준비 동작 - 수어가 끝난 뒤 손을 내리는 동작 - 10개 학습 단어에 포함되지 않은 다른 수어 표정 변화도 NO_SIGN 영상에 자연스럽게 포함될 수 있지만, 표정만 여러 번 촬영하는 것은 부족합니다. 모델 입력에 손·포즈· 얼굴 좌표가 모두 포함되므로 일상적인 손과 몸의 움직임을 다양하게 넣는 것이 중요합니다. 촬영자당 NO_SIGN 20개는 예를 들어 이렇게 나눌 수 있습니다. - 정지 또는 대화 자세: 3개 - 얼굴·머리·안경 만지기: 3개 - 옷이나 소지품 정리: 3개 - 일반적인 손짓: 4개 - 물건 들거나 내려놓기: 3개 - 수어 준비·종료와 비슷한 동작: 2개 - 학습 대상이 아닌 다른 수어: 2개 특히 “학습 대상이 아닌 다른 수어”는 중요합니다. 이것이 없으면 모델이 모르는 수어를 가장 비슷한 10개 단어 중 하나로 억 지로 분류할 가능성이 높습니다. 다만 NO_SIGN에 20종류를 고정하여 모든 촬영자가 똑같이 따라 하기보다는, 항목별 유형만 제시하고 각자 자연스럽게 수행하게 하는 편이 일반화에 유리합니다.
